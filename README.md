# PyMEs Magdalena — Cartografía Interactiva

Mapa interactivo de 38 PyMEs dedicadas al transporte de alimentos perecederos
en el departamento de Magdalena, Colombia.

- 21 ubicaciones geocodificadas (Nominatim/OSM)
- 17 zonas aproximadas por ciudad
- 5 municipios: Santa Marta, Fundación, Ciénaga, Plato, Aracataca

Herramientas 100% gratuitas y open source.
